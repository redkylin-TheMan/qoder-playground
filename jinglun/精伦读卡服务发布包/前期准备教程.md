# 精伦读卡服务前期准备教程

本教程用于安装并启动身份证读卡服务。按顺序执行，不跳步。

## 第一步：安装 Python 32 位运行环境

打开安装文件：

```text
安装文件\python-3.14.5.exe
```

安装界面里能够勾选的选项全部勾选，然后继续安装直到完成。

## 第二步：安装 VC++ x86 运行库

打开安装文件：

```text
安装文件\VC_redist.x86.exe
```

按安装界面继续执行，直到安装完成。

【图片占位：VC++ x86 安装第一步】

【图片占位：VC++ x86 安装完成】

## 第三步：立即重启电脑

Python 和 VC++ 运行库安装完成后，立即重启电脑。

【图片占位：Windows 重启电脑】

## 第四步：启动精伦读卡服务

重启后，打开发布包根目录，双击：

```text
start.bat
```

启动后，服务会进入系统托盘。桌面不会保留命令行窗口。

【图片占位：双击 start.bat】

【图片占位：系统托盘里的精伦读卡服务图标】

## 第五步：确认服务运行状态

点击系统托盘中的精伦读卡服务图标，打开状态窗口。

状态窗口里确认：

```text
服务状态：运行中
端口：8765
```

点击 `打开诊断页` 可以打开本机诊断页面。

【图片占位：服务状态窗口】

【图片占位：诊断页打开成功】

## 第六步：设置开机自启

第一次启动后，程序会询问是否设置为开机自启。点击确认。

如果之前没有设置成功，可以在状态窗口点击 `设置`，再点击 `设置为开机自启`。

【图片占位：开机自启申请弹窗】

【图片占位：设置窗口开机自启按钮】

## 第七步：进入业务系统使用

打开业务系统，进入：

```text
农户管理
```

点击 `新增农户` 或 `编辑`，弹窗打开后读卡器会自动进入等待身份证状态。把身份证放到读卡器上，读取成功后会自动填写姓名和身份证号。

## 常见情况

### 没有托盘图标

重新双击 `start.bat`。如果服务已经运行，会直接打开状态窗口。

### 业务系统提示精伦读卡服务未启动

双击发布包根目录的 `start.bat`，再回到业务系统重新打开农户弹窗。

### 读取不到身份证

检查读卡器 USB 是否插好，把身份证放在读卡器感应区并保持不动。先在状态窗口点击 `打开诊断页`，确认本机服务正常。

### 要关闭服务

点击系统托盘图标，打开状态窗口，点击 `关闭服务`。直接关闭状态窗口不会停止服务。
