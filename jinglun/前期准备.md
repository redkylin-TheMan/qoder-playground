# 精伦 iDR210 浏览器读写 NFC 与读取身份证前期准备

## 1. 硬件和授权

- 精伦 iDR210 或兼容 iDR 系列身份证阅读器。
- USB 数据线，优先插电脑主板 USB 口。
- 合法授权的测试身份证、外国人永久居留证或港澳台居民居住证。
- 合法授权的 NFC/Type A 测试卡，例如 M1、Mifare UltraLight、CPU 卡。

身份证和卡片数据涉及敏感信息，只在已授权场景中读取和写入。

## 2. 设备连接和驱动

- iDR210 USB-HID 型：按 SDK 文档属于免驱 HID 接口，通常直接插 USB 即可。
- 串口型、USB 转串口型、USB 部标型：先安装厂家或单位提供的对应驱动。
- 打开 Windows 设备管理器确认设备正常：
  - HID 型通常显示在人体学输入设备或 HID 相关设备下。
  - 串口型应能看到 COM 口编号。
  - 部标型或旧驱动型应无未知设备或感叹号。

如果厂家测试程序 `ReaderDemo.exe` 无法读卡，本浏览器方案也无法正常读卡。先用厂家程序确认硬件、驱动、USB 口和卡片没有问题。

## 3. 安装 32 位 Python

本项目必须用 32 位 Python，因为当前精伦 SDK 文件 `Sdtapi.dll`、`SavePhoto.dll`、`Dewlt.dll` 都是 32 位 DLL。

1. 打开 Python Windows 下载页：
   <https://www.python.org/downloads/windows/>
2. 选择合适版本的 `Windows installer (32-bit)`。
3. 安装时建议勾选 `Add python.exe to PATH`。
4. 安装完成后在 PowerShell 验证：

```powershell
py -0p
py -3.12-32 -c "import struct; print(struct.calcsize('P')*8)"
```

第二条命令输出必须是：

```text
32
```

如果安装的是 Python 3.11、3.10 或其他版本，把 `3.12` 改成实际版本，例如：

```powershell
py -3.11-32 -c "import struct; print(struct.calcsize('P')*8)"
```

## 4. 准备 VC++ x86 运行库

如果启动时报缺少 `VCRUNTIME*.dll`、`MSVCP*.dll`、`MSVCR*.dll`，安装 Microsoft Visual C++ Redistributable 的 x86 版本。

官方说明页：
<https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist?source=docs&view=msvc-170>

注意安装 x86，不是只安装 x64。32 位 Python 进程加载 32 位 SDK 时需要 x86 运行库。

## 6. 启动服务

双击：

```text
E:\work\test\jinglun\start.bat
```

启动成功后浏览器会打开：

```text
http://127.0.0.1:8765
```

如果 `8765` 被占用，服务会尝试后续端口，并在命令行窗口打印实际地址。

## 7. 操作顺序

1. 插入读卡器。
2. 打开浏览器页面。
3. 点击 `检测服务`，确认 Python 和 SDK 状态。
4. 点击 `检测设备`，查看 HID/部标数量。
5. 端口默认保留 `1001`。
6. 点击 `打开设备`。
7. 身份证读取：把身份证放在读卡器感应区，点击 `读取身份证`。
8. NFC 读写：放置卡片，先 `寻卡` 或 `读卡号`，再执行区块读写或 APDU。

## 8. 常见问题

### 找不到 32 位 Python

`start.bat` 会提示未找到 32 位 Python。安装 `Windows installer (32-bit)` 后重新运行。

### DLL 加载失败

检查：

- 是否用 32 位 Python。
- `native\x86` 是否有四个 SDK 文件。
- 是否安装了 VC++ x86 运行库。

### 打开端口失败

检查：

- 读卡器 USB 是否插好。
- 设备管理器是否正常识别。
- HID 型默认端口是否为 `1001`。
- 串口型是否填写了实际 COM 号对应的数字，例如 COM3 填 `3`。
- 厂家 `ReaderDemo.exe` 是否能正常读卡。

### 身份证认证失败

检查：

- 身份证是否放在感应区并停留。
- 是否先打开设备。
- 读卡器是否带公安部授权 SAM 模块。
- 同一张证默认可能不允许重复读取，可先移开证件后再放回。

### 写 NFC 区块失败

检查：

- 密钥是否正确，默认密钥是 `FFFFFFFFFFFF`。
- 数据是否正好 16 字节 HEX。
- M1 扇区尾块默认禁止写入；确需写入时勾选 `允许写入扇区尾块`。

## 9. 数据处理说明

- 服务绑定 `127.0.0.1`，不对局域网开放。
- 默认不保存身份证文本、照片、指纹或 NFC 数据。
- 浏览器刷新后页面上的读取结果会消失。
- 如需后续接入业务系统，应先补充权限控制、日志脱敏、数据加密和最小化保存策略。
