## 〇、先回答你的核心问题：去哪看单据变更痕迹

### 看一张单"被改过什么、改前什么样"的页面

**路由：`#/op-log`（左侧菜单：系统管理 → 操作日志）**

这是烘干厂版的"粮易智联溯源页"，但粒度细到**单据字段**：
- 列表按「模块 / 动作 / 时间 / 操作人」筛选
- 点某条记录的「详情」→ 右侧抽屉 → **「字段对比」tab**
- 表格逐字段显示 **改前 → 改后**，红字标出变更的字段
- 数据来源：操作日志的 `detailJson`（含 `before` 改前快照 + `after` 改后 DTO）

**对照表（不同操作在 op-log 里的样子）**：

| 操作 | module | 动作 | 字段对比 tab 能看到 |
|---|---|---|---|
| 粮食出库作废 | outbound | void | 改前 status=pending_collect、netWeight、应收 等**全字段** |
| 粮食入库作废 | inbound | void | 改前 status=completed、dryWeight、应付 等**全字段** |
| 农资出库作废 | inputOutbound | void | 改前单据全字段 |
| 农资入库作废 | inputInbound | void | 改前单据全字段 |
| **就地修改字段** | **billEdit** | **edit** | **改前 netWeight=100** + 改后 newValue=80 |
| 财务核查退款 | financeConfirm | refund | 改前 collectedAmount 等 |

### 另一条更底层的溯源（触发器自动写）

后端还有 `/hl-drying/drying/change-log/list?bizNo=CK...`（Oracle 触发器在每次 UPDATE 落库时自动记的字段级新旧值），比 op-log 更底层，连数据库直改都能抓到。前端暂无专门页面，可用接口查。

## 二、本轮修复的 3 个缺陷（测试中发现并已修）

| # | 缺陷 | 根因 | 修复 | 状态 |
|---|---|---|---|---|
| 1 | 粮食出库作废全部失败 `ORA-02290` | 两个 `@PostConstruct` 迁移 drop+add 同一个 `CK_DCF_BIZ_TYPE` 约束，T-125 旧列表覆盖了 V2.2 的 `grain_out_void` 等枚举 | 两处 Java 列表统一为全集 | ✅ 已生效 |
| 2 | 就地修改/财务核查**操作日志全丢** | `EditFieldDTO`/`FinanceConfirmDTO` 无 factoryId，AOP 写 op-log 时 `factory_id=NULL` 撞 `ORA-01400` | AOP 切面 `extractFactoryId` 兜底（登录态反查厂） | ✅ 已生效 |
| 3 | 就地修改的 op-log **只有改后、没改前** | `BillEditEntityFetcher` 漏写 + `ID_FIELDS` 白名单缺 `billId`，AOP 抠不出业务对象 ID → 不抓 before | 新增 fetcher + ID_FIELDS 加 billId | ✅ 已生效 |

### 5.3 直连数据库查表（最权威）

```sql
-- 操作日志（改前改后对比的原始数据）
SELECT MODULE, ACTION, SUMMARY, OP_USER_NAME,
       TO_CHAR(OP_TIME,'MM-DD HH24:MI') T,
       LENGTH(DETAIL_JSON) DETAIL_LEN   -- before/after 都在这
FROM TBL_DRYING_OP_LOG
WHERE FACTORY_ID='2062754110754656256'
ORDER BY OP_TIME DESC;

-- 字段变更溯源（触发器自动写，含改前/改后/操作原因）
SELECT TABLE_NAME, BIZ_NO, CHANGED_FIELD, OLD_VALUE, NEW_VALUE,
       CLIENT_INFO, TO_CHAR(CHANGE_TIME,'MM-DD HH24:MI') T
FROM TBL_DRYING_CHANGE_LOG
WHERE FACTORY_ID='2062754110754656256'
ORDER BY CHANGE_TIME DESC;

-- 库存流水（每次±留痕）
SELECT BIZ_TYPE, QTY_BEFORE, QTY_CHANGE, QTY_AFTER, REF_BILL_ID,
       REMARK, TO_CHAR(OP_TIME,'MM-DD HH24:MI') T
FROM TBL_DRYING_STOCK_LOG
WHERE FACTORY_ID='2062754110754656256'
ORDER BY OP_TIME DESC;
```
